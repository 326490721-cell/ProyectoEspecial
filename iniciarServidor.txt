PRUEBA DEL INICIO DE SESION - FRIKSIX ARCADE

1. Abre este proyecto en VS Code y confirma que la carpeta abierta sea:
   D:\Paginas\ProyectoEspecial

2. Inicia MySQL desde el panel de XAMPP. Debe aparecer como iniciado.

3. En VS Code, presiona Ctrl+Shift+P, elige "Tasks: Run Task" y ejecuta:
   FrikSix: iniciar sitio web
   Deja abierta la terminal de esa tarea mientras pruebas el sitio.

4. Abre exactamente esta direccion:
   http://127.0.0.1:8000/logIn.html
   No abras el archivo con file:// ni uses Live Server (puerto 5500).

5. Prueba que se rechacen las credenciales:
   - Escribe un nombre de usuario registrado y una contraseña incorrecta de
     al menos 12 caracteres ASCII, por ejemplo: PruebaIncorrecta123
   - Presiona "Iniciar sesion".
   - Debe volver al formulario y mostrar:
     "El usuario o la contraseña son incorrectos."
   - No uses una contraseña real en esta prueba.
   - Tambien puedes probar un usuario inventado con la misma contraseña falsa;
     el mensaje debe ser el mismo para no revelar si existe una cuenta.

6. Prueba el acceso correcto:
   - Inicia sesion con tu nombre de usuario y contraseña habituales.
   - Debe abrirse el panel y mostrar tu usuario, perfil y accesos disponibles.
   - El perfil Contador puede ver el acceso para registrar proveedores si
     tiene el permiso correspondiente.

7. Presiona "Cerrar sesion". Debe regresar al formulario.
   Si abres directamente http://127.0.0.1:8000/scripts/dashboard.php sin
   iniciar sesion, el sitio debe regresarte al formulario.

8. Cuando termines, vuelve a la terminal de la tarea y presiona Ctrl+C para
   detener el servidor PHP.

Solucion de problemas:
- Si la pagina no abre, confirma que la tarea siga ejecutandose y que MySQL
  este iniciado en XAMPP.
- Si el puerto 8000 ya esta ocupado, detén la otra tarea "FrikSix: iniciar
  sitio web" antes de volver a iniciarla.
- Si aparece codigo PHP en el navegador, detente: estas usando un servidor
  estatico o una direccion incorrecta. Usa la direccion exacta del paso 4.
- Diez intentos fallidos desde la misma direccion IP en 15 minutos bloquean
  nuevos intentos temporalmente. Espera 15 minutos antes de volver a probar.
- No guardes ni compartas contraseñas en este archivo, capturas o mensajes.
