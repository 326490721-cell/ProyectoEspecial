# ProyectoEspecial
1. Organización: Formar el equipo de tres integrantes, repartir responsabilidades y planear el proyecto.

2. Investigación de mercado: Identificar clientes potenciales, competencia, ubicación y necesidades del negocio.

3. Identidad empresarial: Crear nombre, logotipo, eslogan, misión, visión y valores.

4. Presentación: Elaborar la portada con escudos institucionales, nombres de profesoras e integrantes y grupos 61B y 61C.

5. Recursos: Investigar máquinas Arcade, consolas, videojuegos, mobiliario, proveedores, instalaciones y costos.

6. Personal: Definir los empleados y sus funciones.

7. Contabilidad y legalidad: Investigar permisos, documentos, inversión inicial, gastos, precios y ganancias.

8. Catálogo: Seleccionar 20 categorías de videojuegos y entretenimiento, con imágenes y precios.

9. Publicidad: Crear redes sociales, anuncios y promociones.

10. Computación: Diseñar una página web con catálogo, precios, ubicación y contacto.

11. Entrega final: Integrar las investigaciones, revisar el proyecto y preparar la presentación
