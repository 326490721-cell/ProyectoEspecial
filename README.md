# ProyectoEspecial

Este repositorio contiene un proyecto de landing page para un negocio de arcade y entretenimiento, con una propuesta visual estilo retro y un catálogo de productos y servicios.

## Estructura recomendada

- `index.html`: archivo principal de entrada del sitio.
- `main.html`: redirección de compatibilidad para mantener acceso al archivo original.
- `assets/css/style.css`: estilos del proyecto.
- `assets/js/app.js`: lógica ligera para la experiencia del sitio.
- `*.jpg`: recursos gráficos del catálogo.

## Cómo visualizarlo

1. Abre `index.html` en tu navegador.
2. Si usas GitHub Pages, el sitio quedará disponible con la carpeta raíz del proyecto.

## Ajustes realizados

- Se organizó la estructura del proyecto en carpetas de código.
- Se corrigió la falta de punto de entrada principal (`index.html`).
- Se eliminó la dependencia de un fondo roto (`Sprites/BagGround.gif`) para evitar errores visuales.
- Se mejoró la experiencia del sitio con navegación, catálogo y contacto.
